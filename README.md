# Хомус Коваценко (Kovatsenko) — Telegram Mini App

**Это прототип.** Товары, цены, описания и фото взяты из VK-магазина https://vk.com/market-73004917 (6 варганов + 2 опции). Платежи НЕ подключены: каждый способ оплаты показывает демо-шаг. Способы оплаты: крипта (USDT/TON), карта РФ, международная карта.

## Структура
- `index.html`, `css/style.css`, `js/app.js` — статический сайт без сборки.
- `js/data.js` — товары (`PRODUCTS`) и опции (`OPTIONS`: покрытие «под золото», гравировка чехла). Опции выбираются на странице варгана или в корзине. Цены в ₽.
- `img/*.jpg` — фото из VK, уменьшенные до 1280px.
- Описания и тексты постов — дословно из VK. Видео скачаны и хранятся в `video/` (H.264/AAC, faststart, с постерами); экран «Послушать звучание» работает без VK. Кнопки «Купить в VK» ведут в VK-магазин.
- Шапка: аватар и «Хомус Коваценко»; по нажатию — страница «О мастере» (телефон, shkolavargana.ru, сообщество VK).

## Локальный запуск
```
python3 -m http.server 8000   # открыть http://localhost:8000
```
Вне Telegram главная кнопка рисуется внизу страницы, «Назад» — обычной кнопкой.

## Запуск в Telegram
1. В @BotFather: `/newbot` → получить токен бота (хранить в секрете, только на сервере).
2. Выложить папку на HTTPS-хостинг (Telegram требует HTTPS):
   - **Cloudflare Pages** / **Vercel** / **Netlify**: перетащить папку или подключить репозиторий; сборка не нужна.
   - **GitHub Pages**: залить в репозиторий → Settings → Pages.
3. В @BotFather: `/mybots` → бот → Bot Settings → **Menu Button** → указать URL сайта и текст («Магазин»).
   Дополнительно можно `/newapp`, чтобы получить прямую ссылку `t.me/<бот>/<app>`.
4. Открыть бота → кнопка меню → магазин откроется как мини-приложение (тема, MainButton, BackButton — из Telegram WebApp API).

## Куда подключать платежи (`js/app.js`)
Все секретные ключи — только на бэкенде; фронт вызывает ваш `/api/...`.
- `createCryptoInvoice()` — **Crypto Pay API** (@CryptoBot, метод `createInvoice`, USDT/TON) или NOWPayments. Фронт открывает `pay_url`, статус приходит webhook-ом.
- `createCardPayment(order,'rf')` — **ЮKassa** (`POST /v3/payments`) / **CloudPayments** / **Т-Банк**. Нужен российский получатель (ИП/ООО/самозанятый).
- `createCardPayment(order,'intl')` — **Stripe Checkout Session**. Доступность для вашей страны/юрлица надо проверить у Stripe.
- Крипта: цена в ₽, сумма в USDT/TON подтверждается вручную (или Crypto Pay с `fiat=RUB`).

Подтверждать оплату только по webhook провайдера, а не по нажатию «Я оплатил».

## Как заказы попадают владельцу
Мини-бэкенд (Cloudflare Worker, Vercel Function, или ~30 строк на Node/Python):
1. Принимает `POST /api/order`.
2. Проверяет подпись `Telegram.WebApp.initData` (HMAC с токеном бота — см. документацию «Validating data received via the Mini App»).
3. Шлёт владельцу сообщение: `https://api.telegram.org/bot<TOKEN>/sendMessage` с `chat_id` владельца (фото — `sendMediaGroup`).
4. Получает webhook-и платёжек и отмечает заказ оплаченным (опционально — Google Sheets/Notion как база).

## Ограничения прототипа
- Нет бэкенда, заказы никуда не уходят, корзина не сохраняется после перезагрузки.
- Товары захардкожены в `js/data.js` (без синхронизации с VK). Видео нет.
- Нет валидации полей и расчёта доставки.
